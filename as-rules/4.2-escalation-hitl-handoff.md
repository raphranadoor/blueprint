# Rule: 4.2 Escalation and Human-in-the-Loop Handoff Specification

**Stage:** 4 — Behavioral Specification and Governance

## Slots
Purpose · Contents · Gate · Boundary · Bridge

## Purpose
How a run hands off to a human when ABS stop/escalate rules fire against AA HITL gates. ABS decides when; this artifact decides how.

## Required sections
1. Escalation triggers (map from ABS + AA risk tiers)
2. Handoff protocol (payload, channel, form)
3. Human decision points and required responses
4. Resume / continue rules after human input
5. Timeouts and fallback if human does not respond
6. Escalation logging mechanisms (what/where/who/retention)

**Out (do not include):** system prompts/full behavior policies; Policy-as-Code detail; TC schemas; system-wide Observability Plan

## Artifact acceptance gate
All answers must be YES to approve:
1. Every AA risk-tiered HITL gate has a defined handoff path?
2. Every ABS stop/escalate rule maps to a handoff or resume path?
3. Handoff payload and required human responses stated?
4. Resume/continue rules and timeouts/fallback stated?
5. Escalation logging mechanisms stated?

## Boundary
Operable handoff mechanics for human checkpoints.

## Bridge
→ Governance and Safety Policies.
