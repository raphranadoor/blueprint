# Rule: 5.3 Simulation Scenarios

**Stage:** 5 — Implementation, Deployment, and Validation

## Slots
Purpose · Contents · Gate · Boundary · Bridge

## Purpose
Runnable exercises that stress the system against the Evaluation Plan and Failure Taxonomy before deployment architecture is finalized.

## Required sections
1. Scenario inventory
2. Mapping to Failure Taxonomy entries
3. Setup and inputs
4. Expected failure or recovery behavior
5. Pass criteria for simulation runs

**Out (do not include):** Deployment Architecture topology; Observability Plan dashboards

## Artifact acceptance gate
No separate YES/NO checklist. Accept when sections are complete, scenarios exercise the case space/taxonomy, and the approver confirms.

## Boundary
Adverse/recovery scenarios before finalizing deployment architecture.

## Bridge
→ Deployment Architecture and Observability Plan.
