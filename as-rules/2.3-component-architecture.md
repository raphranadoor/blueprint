# Rule: 2.3 Component Architecture

**Stage:** 2 — System Design

## Slots
Purpose · Contents · Gate · Boundary · Bridge

## Purpose
Concrete runtime structure from PRD+SRS, Domain Model, and accepted TLA+ property-set. Decide components, interfaces, stores/external services, and reasoning points.

## Required sections
1. Components — each cites PRD/SRS need(s), Domain Model ground(s), TLA+ property(ies)
2. Interfaces between components (structure-level; not Tool Contracts)
3. Stores and external services
4. Reasoning points

**Out (do not include):** agent roles, coordination protocols, Tool Contracts detail, prompts, schemas/code

## Artifact acceptance gate
All answers must be YES to approve:
1. PRD and SRS used as paired inputs?
2. Accepted Domain Model version named?
3. Accepted TLA+ Spec version with PASS named?
4. Components decided?
5. Interfaces decided?
6. Stores and external services decided?
7. Reasoning points decided?

**Hard rules:** no Spec PASS ⇒ C3 NO.

## Boundary
Runtime piece arrangement and reasoning-point markers — not agent behavior.

## Bridge
Completes Stage 2 → Stage 3 Tool Contracts.
