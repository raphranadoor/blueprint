### Purpose
Evaluation (EVAL) defines how the agent system is judged and how failures are classified when judgment fails. The Evaluation Plan states evaluation objectives, the versioned case set, metrics and thresholds, procedures and environments, and pass/fail rules linked to those cases, bound to the IP build and test sequencing. The Failure Taxonomy states failure categories, severity, detectability and signals, example instances, and remediation owners.
