# Escalation and Human-in-the-Loop Handoff Specification

**Id:** `4.2` · **Stage:** 4 — Behavioral Specification and Governance · **Version:** `v0.1-DRAFT`

## Normative

### Purpose
How a run hands off to a human when ABS stop/escalate rules fire against AA HITL gates. ABS decides when; this artifact decides how.

### Required sections
1. Escalation triggers (map from ABS + AA risk tiers)
2. Handoff protocol (payload, channel, form)
3. Human decision points and required responses
4. Resume / continue rules after human input
5. Timeouts and fallback if human does not respond
6. Escalation logging mechanisms (what/where/who/retention)

**Excluded:** system prompts/full behavior policies; Policy-as-Code detail; TC schemas; system-wide Observability Plan
